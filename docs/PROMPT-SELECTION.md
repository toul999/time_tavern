# 對話預設快速切換

對話上方工具列的「對話預設」圖示會開啟設定視窗，內有「模式預設」與「正文規則」兩個選單，選擇後自動保存，下次生成生效。助手使用自己的提示詞，不套用這兩項。

- 模式預設選「跟隨角色卡」時，沿用角色卡的模式；指定其他模式只影響目前對話，不修改角色卡。
- 正文規則選「跟隨模式」時，使用所選模式的正文；指定其他規則時，只替換正文主要規則與正文輸出規則，其他設定及提示詞排列順序維持原樣。
- 切換模式仍保留已選的正文規則。例如角色卡 A、對話模式 B、正文規則 C，結果為 B 的其他設定加 C 的兩欄正文。
- 舊對話及新開始的對話預設跟隨角色卡／模式。選擇隨對話故事及對話存檔保存，重新啟動仍保留。

「編輯模式」沿用原 Prompt 編輯器及保存、匯入／匯出功能。「管理正文」可新增、保存、另存新版本、刪除、匯入及匯出成對的正文規則，也可從目前模式帶入內容。保存修改的是共用收藏，所有選用它的對話都使用新版；要保留舊版請另存新版本。管理正文不會自動選用，請從對話選單指定。

正文 JSON 匯入後先顯示在編輯器，確認並保存才建立新規則，不覆蓋既有收藏。匯出的是編輯器目前內容。刪除後，原本引用它的對話退回跟隨模式，畫面會顯示引用已刪除。

## 儲存及備份

| 資料 | 位置 |
|---|---|
| 整套模式 | 沿用 `data/app-defaults.json`、`data/app-state.json` 的 `modularPromptConfigs` |
| 正文規則收藏 | `data/body-rule-presets.json`，首次保存時建立 |
| 對話選擇 | `data/conversation-contexts/` 故事及既有對話存檔的 `promptSelection` |

選擇以固定 ID 引用收藏，改名不會失去關聯。收藏不存在時回退跟隨設定；損壞的收藏檔會報錯，不自動覆寫。

整份 data ZIP 備份會包含正文收藏與對話選擇。角色卡備份及全局設定備份不包含獨立正文收藏，跨裝置可使用整份 data 或單獨匯出／匯入正文規則。

## 自訂補充版本

使用者設定的自訂補充欄位提供原地版本選單、空白新增及更多操作，無須另開管理視窗。另存、改名與未保存提醒在欄位旁展開。

切換版本只載入編輯框，按「儲存使用者設定」才會全局生效。收藏版本與已套用文字分開保存：另存、更新、改名、刪除收藏都不會直接改變目前生效的文字。未保存內容切換前可選擇繼續或保留內容；背景重新整理會保留編輯中的草稿。

更多選單提供更新目前版本、改名、刪除、匯入及匯出。匯入建立新版本，匯出保存目前編輯框內容。收藏放在 data/supplement-presets.json，已選版本 ID 隨 userProfile.supplementPresetId 保存，實際生效文字仍使用原本的 userProfile.identityText。整份 data 備份包含收藏；角色卡及全局設定備份不含獨立收藏，可另外匯出版本移植。
